A make.fun entry: one single-line joke giving an excuse for missing a deadline, capped at 200 characters.

> Technically it's not late, I'm just working on Hawaii time for the moment.

The program writes exactly that line to `/output/entry.txt` (74 characters, within the 1–200 gate), with a gate guard that fails loudly if the line ever drifts outside the limit and a read-back check that verifies the file matches the line byte for byte.
